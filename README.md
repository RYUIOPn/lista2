# ☕ Segunda lista de Java ☕

Este repositório contém uma série de exercícios práticos focados em **Domain Driven Design (DDD)**, objetivo é aplicar os pilares da Orientação a Objetos e boas práticas de desenvolvimento Java.

## 🚀 Conceitos Aplicados

### 1. Modelagem e Estrutura
**Classes e Objetos:** Criação de moldes para representação de entidades do mundo real
**Variáveis de Instância:** Definição de estados de objeto utilizando tipos primitivos (`int`, `double`) e objetos (`String`)
**Construtores:** Implementação de métodos de inicialização obrigatória com chamadas internas para validação

### 2. Encapsulamento e Integridade
**Modificadores de Acesso:** Uso de visibilidade `private` para proteção de atributos sensíveis
**Métodos Getters e Setters:** Controle de acesso e modificação de dados via interface pública
**Lógica de Validação:** Filtros para impedir estados inválidos, como valores negativos ou estourar o limite de saldo

### 3. Comportamento e Algoritmos
**Métodos com Retorno:** Funções para cálculos de tempo e lógica financeira
**Assinatura de Métodos:** Definição técnica de parâmetros e tipos de retorno conforme requisitos do sistema
**Composição:** Refatoração de arquitetura para reutilização de objetos como atributos de outras classes

### 4. Interface e Ferramentas
**Entrada de Dados (Scanner):** Captura e processamento de dados via console
**Saída de Dados Formatada:** Uso de máscaras de texto e controle de casas decimais com `printf`
**Documentação Javadoc:** Escrita de metadados técnicos para classes e construtores seguindo o padrão da indústria

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem:** Java (JDK 17+)
* **Entrada de Dados:** `java.util.Scanner` 
* **Paradigma:** Orientação a Objetos (POO)
